# BYNDCART Courier Integration Guides

The courier registry includes PostEx, Leopards, DHL Express, FedEx and TCS adapters. Integrations must be configured and tested using each merchant's own account before they are selected as defaults or used for shipment booking.

- [PostEx Merchant API](POSTEX.md)
- [Leopards eCom Merchant API](LEOPARDS.md)
- [DHL Express MyDHL API](DHL.md)
- [FedEx Ship and Track APIs](FEDEX.md)
- [TCS COD API](TCS.md)
- [Overall live/disabled status and release checklist](../COURIER_INTEGRATION_STATUS.md)

TRAX, M&P, Call Courier and Rider remain disabled because this package does not supply their current official contracts plus complete implementations. Do not re-register a disabled adapter without verified documentation, tests and carrier UAT.
